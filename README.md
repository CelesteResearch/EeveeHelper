# EeveeHelper

EeveeHelper port for the Shared runtime. Workspace location: `Mods/EeveeHelper/`.

Projects:

- `Celeste.Mods.EeveeHelper.csproj`

Repository dependencies: **Shared**. Prepare Shared resources using the [Tools README][tools-readme], then build the main project:

```powershell
dotnet build ./Mods/EeveeHelper/Celeste.Mods.EeveeHelper.csproj -c Release
```
